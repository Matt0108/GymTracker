Project Name: Gym Tracker

The purpose of my application is to allow users to keep track of their gym workouts and exercises. Users will eventually be able to create an account, log in, and record information about the exercises they perform.

The intended users are people who go to the gym and want a simple way to keep track of their workouts.

Main Features:
- User registration
- User login
- Add exercise entries
- Record exercise information such as exercise name, weight, sets, and repetitions
- View exercise entries
- Edit exercise entries
- Delete exercise entries

The two main entities in the application will be Users and Exercise Entries.
